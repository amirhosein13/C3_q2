# راهنمای بارگذاری مسئله در پنل مدیریت سی‌ام‌اس

این راهنما برای کسی نوشته شده که فقط به پنل وب مدیریت دسترسی دارد و هیچ دسترسی‌ای به سرور یا خط فرمان ندارد. همهٔ فایل‌هایی که لازم دارید در پوشهٔ زیر قرار دارند:

```
cells/cms_upload/
```

محتوای این پوشه:

```
statement.pdf
tests.zip
score_type.txt
task_settings.txt
attachments/sample-01.in
attachments/sample-01.out
attachments/sample-02.in
attachments/sample-02.out
attachments/sample-03.in
attachments/sample-03.out
```

پاسخ این مسئله یکتاست (یک عدد صحیح)، بنابراین به بررسی‌کنندهٔ اختصاصی نیازی نیست و از مقایسه‌گر پیش‌فرض سامانه استفاده می‌کنیم. به همین دلیل فایل بررسی‌کننده در بسته وجود ندارد.

همهٔ مقادیری که باید وارد کنید در فایل زیر هم آمده است و می‌توانید آن را کنار این راهنما باز نگه دارید:

```
cms_upload/task_settings.txt
```

نکته: نام دکمه‌ها و فیلدها در نسخه‌های مختلف سامانه کمی فرق می‌کند. این راهنما بر اساس نسخه‌های ۱٫۴ و ۱٫۵ نوشته شده است. اگر برچسبی دقیقاً یکسان نبود، نزدیک‌ترین برچسب را انتخاب کنید.

## ۴. تنظیم مجموعه‌داده

در پایین صفحهٔ مسئله، بخش مجموعه‌داده‌ها قرار دارد. هنگام ساختن مسئله یک مجموعه‌دادهٔ فعال به‌طور خودکار ساخته شده است. اگر چنین نیست، با پیوند زیر یکی بسازید:

```
Add dataset
```

مقادیر زیر را وارد کنید.

### محدودیت زمان

نام فیلد:

```
Time limit
```

مقدار (واحد این فیلد ثانیه است):

```
3
```

### محدودیت حافظه

نام فیلد:

```
Memory limit
```

مقدار (واحد این فیلد در نسخه‌های ۱٫۴ و ۱٫۵ مبی‌بایت است؛ بخش عیب‌یابی را هم ببینید):

```
512
```

### نوع مسئله

نام فیلد:

```
Task type
```

مقدار:

```
Batch
```

پس از انتخاب این نوع، سه گزینهٔ زیر ظاهر می‌شود.

گزینهٔ کامپایل:

```
Compilation
```

مقدار آن:

```
Submissions are self-sufficient
```

گزینهٔ ورودی و خروجی؛ هر دو فیلد نام فایل را **خالی** بگذارید تا برنامه از ورودی و خروجی استاندارد استفاده کند:

```
I/O (input file name)
```

```
I/O (output file name)
```

گزینهٔ ارزیابی خروجی:

```
Output evaluation
```

مقدار آن (مقایسه‌گر پیش‌فرض که فاصله‌ها و خط‌های اضافه را نادیده می‌گیرد):

```
Outputs compared with white diff
```

### نوع امتیازدهی

نام فیلد:

```
Score type
```

مقدار:

```
GroupMin
```

### پارامترهای امتیازدهی

نام فیلد:

```
Score parameters
```

متن زیر را **دقیقاً** و بدون تغییر بچسبانید. همین متن در فایل پارامترهای امتیازدهی داخل پوشهٔ بارگذاری هم آمده است:

```
[[0, "^00-[0-9]+$"], [8, "^01-[0-9]+$"], [12, "^(00|02)-[0-9]+$"], [15, "^(00|02|03)-[0-9]+$"], [25, "^(00|02|03|04)-[0-9]+$"], [40, "^[0-9]+-[0-9]+$"]]
```

معنای هر گروه در جدول زیر آمده است. نام هر آزمون به شکل «شمارهٔ زیرمسئله، خط تیره، شمارهٔ آزمون» است و آزمون‌های زیرمسئله‌های کوچک‌تر در زیرمسئله‌های بزرگ‌تر هم استفاده می‌شوند:

| زیرمسئله | امتیاز | محدودیت | آزمون‌ها |
|:-:|:-:|:-:|:-:|
| ۰ | ۰ | نمونه‌ها | `00-*` |
| ۱ | ۸ | همهٔ خانه‌ها آزاد | `01-*` |
| ۲ | ۱۲ | `n, m <= 15` | `00-*` و `02-*` |
| ۳ | ۱۵ | `n, m <= 50` | `00-*` تا `03-*` بدون `01-*` |
| ۴ | ۲۵ | `n, m <= 300` | `00-*` تا `04-*` بدون `01-*` |
| ۵ | ۴۰ | بدون محدودیت اضافه | همهٔ آزمون‌ها |

در پایان، دکمهٔ ذخیرهٔ پایین صفحه را بزنید:

```
Update
```

## ۵. بررسی‌کننده

این مسئله به بررسی‌کننده نیاز **ندارد**، چون پاسخ یکتاست. بنابراین در بخش مدیرها هیچ فایلی بارگذاری نکنید:

```
Managers
```

فقط مطمئن شوید که در بخش چهارم این گزینه انتخاب شده باشد:

```
Outputs compared with white diff
```

اگر به‌اشتباه گزینهٔ زیر را انتخاب کنید، سامانه دنبال فایل بررسی‌کننده در بخش مدیرها می‌گردد و چون چنین فایلی وجود ندارد، همهٔ ارسال‌ها با خطا روبه‌رو می‌شوند. این گزینه را انتخاب **نکنید**:

```
Outputs are checked by a comparator
```

(برای استفادهٔ محلی، کد یک بررسی‌کنندهٔ مقایسهٔ واژه‌به‌واژه در مسیر زیر هست، ولی برای سامانه لازم نیست.)

```
cells/checker/checker.cpp
```

## ۹. عیب‌یابی

### الف) خطای اجرای بررسی‌کننده

اگر در نتیجهٔ ارسال‌ها پیام‌هایی شبیه این دیدید:

```
Execution failed
```

```
Evaluation failed / checker not executable
```

علت تقریباً همیشه این است که گزینهٔ ارزیابی خروجی روی حالت بررسی‌کننده مانده است. در صفحهٔ مجموعه‌داده این گزینه را به مقدار زیر برگردانید و ذخیره کنید:

```
Outputs compared with white diff
```

سپس ارسال‌ها را دوباره ارزیابی کنید. در صفحهٔ مسئله یا مجموعه‌داده دکمهٔ زیر را بزنید:

```
Reevaluate
```

(اگر روزی بخواهید از بررسی‌کنندهٔ اختصاصی استفاده کنید، فایل باید یک برنامهٔ ایستای لینوکس و بدون پسوند باشد که در بخش مدیرها با نام دقیق زیر بارگذاری می‌شود. برای این مسئله لازم نیست.)

```
checker
```

### ب) صفر شدن امتیاز به‌خاطر عبارت باقاعدهٔ نادرست

نشانه‌ها: راه‌حل اصلی همهٔ آزمون‌ها را درست حل می‌کند ولی امتیاز کل صفر یا ناقص است، یا ذخیرهٔ صفحه با خطا روبه‌رو می‌شود.

علت‌های رایج و راه‌حل:

۱. متن پارامترها کامل چسبانده نشده یا علامت نقل‌قول هوشمند جای علامت نقل‌قول ساده نشسته است. متن را دوباره از فایل زیر کپی کنید و در یک ویرایشگر متن ساده بچسبانید:

```
cms_upload/score_type.txt
```

۲. نام آزمون‌ها با پیشوندها نمی‌خواند. در فهرست آزمون‌ها، نام‌ها باید دقیقاً به این شکل باشند (بدون پسوند):

```
00-01
```

اگر نام‌ها به شکل زیر هستند، یعنی قالب ورودی و خروجی را اشتباه وارد کرده‌اید:

```
00-01.in
```

همهٔ آزمون‌ها را حذف کنید و بارگذاری گروهی را با این دو قالب تکرار کنید:

```
*.in
```

```
*.out
```

۳. نسخهٔ بسیار قدیمی سامانه از عبارت باقاعده پشتیبانی نمی‌کند و به‌جای آن تعداد آزمون‌ها را می‌خواهد. در آن صورت آزمون‌ها باید پشت‌سرهم و بدون اشتراک باشند و این بسته با آن نسخه سازگار نیست؛ نسخه را ارتقا دهید یا به مدیر سرور اطلاع دهید.

پس از هر اصلاح، صفحه را ذخیره و دکمهٔ زیر را بزنید تا امتیازها دوباره محاسبه شوند:

```
Reevaluate
```

### ج) اشتباه در واحد محدودیت حافظه

در نسخه‌های ۱٫۴ و ۱٫۵ واحد این فیلد مبی‌بایت است و مقدار درست این است:

```
512
```

اگر نسخهٔ شما بایت می‌خواهد (برچسب فیلد واحد را نشان می‌دهد)، این مقدار را وارد کنید:

```
536870912
```

نشانهٔ اشتباه: اگر به‌جای ۵۱۲ مبی‌بایت عددی بسیار کوچک ثبت شود، حتی نمونه‌ها هم با خطای حافظه یا خطای اجرا رد می‌شوند. اگر عدد بایت را در فیلد مبی‌بایت بنویسید، محدودیت عملاً برداشته می‌شود و ممکن است سامانه خطا بدهد. راه‌حل اصلی حدود ۱۱۵ مبی‌بایت حافظه مصرف می‌کند.

### د) نام‌گذاری نادرست در فایل فشرده

نشانه‌ها: تعداد آزمون‌ها پس از بارگذاری کمتر از ۹۷ است، یا پیام خطایی دربارهٔ پیدا نشدن خروجی می‌بینید.

بررسی‌ها و راه‌حل‌ها:

۱. قالب‌ها باید دقیقاً این دو مقدار باشند و ستاره باید باشد:

```
*.in
```

```
*.out
```

۲. فایل فشرده را از حالت فشرده خارج نکنید و دوباره نسازید؛ همان فایل اصلی را بارگذاری کنید. اگر سیستم‌عامل شما هنگام فشرده‌سازی دوباره یک پوشه در ریشهٔ فایل اضافه کند، سامانه آزمون‌ها را پیدا نمی‌کند.

۳. اگر بارگذاری بار اول نیمه‌کاره ماند، گزینهٔ زیر را تیک بزنید و دوباره بارگذاری کنید:

